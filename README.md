# RDP (rdp)
The Remote Desktop Protocol (RDP) is a proprietary network protocol developed by Microsoft that provides a graphical interface to connect to another computer over a network. RDP transmits keyboard, mouse, display, and audio data between client and host, enabling remote administration, virtual desktops, and remote work scenarios. The protocol typically operates on TCP and UDP port 3389 and is implemented by Microsoft's Remote Desktop Services as well as third-party clients across Windows, macOS, Linux, iOS, and Android. This index also acknowledges the use of the RDP acronym for Refinitiv (LSEG) Data Platform in the financial data context.
